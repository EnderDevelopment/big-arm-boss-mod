# Big Arm Boss Mod

A massive mechanical boss mod for Minecraft Bedrock Edition

## Features

- Massive mechanical boss with 400 hearts health
- Two arm-mounted cannons
- 100 XP reward upon defeat
- Custom crafting recipe for the Big Arm Spawner
- Custom loot tables and animations

## Requirements

- Minecraft Bedrock Edition 1.21.4
- Fabric Loader 0.14.0 or higher

## Installation

1. Download the latest release from the [Releases](https://github.com/EnderDevelopment/big-arm-boss-mod/releases) page.
2. Place the JAR file in your `mods` folder.
3. Launch Minecraft Bedrock Edition with Fabric Loader.

## Usage

### Crafting the Big Arm Spawner

To craft the Big Arm Spawner, you need:

- 8 Diamonds
- 1 Iron Ingot

The crafting recipe is as follows:

```
DDD
DID
DDD
```

### Spawning the Big Arm Boss

1. Craft the Big Arm Spawner using the recipe above.
2. Place the Big Arm Spawner in the world.
3. Right-click the Big Arm Spawner to spawn the Big Arm Boss.

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
